# 🏝️ Escape the Mysterious Island

## About the Project
Escape the Mysterious Island is a text-based adventure
game developed using Python.

The player must make decisions to survive dangerous
situations and successfully escape the island.

This project was built as part of my 100 Days of
Python learning journey.

## Features
- Interactive adventure gameplay
- Multiple decision paths
- Four challenging stages
- Winning and losing scenarios
- Input validation
- Case-insensitive user input

## Python Concepts Used
- Variables
- Input and output functions
- Conditional statements
- Nested if statements
- if, elif, and else
- String methods: strip() and lower()

## How to Play
1. Run escape_island.py.
2. Follow the instructions displayed.
3. Make your choices carefully.
4. Avoid dangerous situations.
5. Find the hidden boat and escape!
